How do I create a controller and a service in Java?

1. Create the service. It holds the business logic.

Java
@Service
public class UserService {
  public List<User> findAll() {
    return repository.findAll();
  }
}

2. Create the controller. It exposes the service over HTTP.

Java
@RestController
@RequestMapping("/users")
public class UserController {
  private final UserService service;
  @GetMapping
  public List<User> list() {
    return service.findAll();
  }
}

Spring injects the service through the constructor.
